# ParameterShift

ParameterShift provides exact parameter-shift differentiation for variational
quantum algorithms without coupling the differentiation layer to a specific
PyQPanda execution backend.

For a gate generated by a two-eigenvalue Hermitian generator with spectral gap
r:

~~~text
U(theta) = exp(-i theta G)
d f / d theta = r/2 * [f(theta + pi/(2r)) - f(theta - pi/(2r))]
~~~

The common RX/RY/RZ convention uses G=P/2, so r=1.

## Local gradient

~~~python
import numpy as np
from pyqpanda_alg.ParameterShift import parameter_shift_gradient

def expectation(theta):
    # Replace this pure example with CPUQVM/QCloud observable evaluation.
    return np.cos(theta[0]) + 0.25 * np.cos(theta[1])

gradient = parameter_shift_gradient(expectation, [0.2, -0.4])
print(gradient)
~~~

## QCloud / QPU batch workflow

Building the schedule is intentionally separate from backend execution. This
lets an application submit every shifted circuit in one remote batch:

~~~python
from pyqpanda_alg.ParameterShift import build_shift_schedule

schedule = build_shift_schedule([0.2, -0.4])

# points = schedule.points
# results = qcloud_batch(points)
# jacobian = schedule.reconstruct(results)
~~~

Every schedule entry carries the shifted parameter vector, derivative
coefficient, parameter index and term index, so results can be persisted and
reconstructed deterministically.

## Custom generator gaps

Use one rule per circuit parameter when generators have different spectral
gaps:

~~~python
from pyqpanda_alg.ParameterShift import ParameterShiftRule, parameter_shift_gradient

rules = [
    ParameterShiftRule.two_eigenvalue(1.0),
    ParameterShiftRule.two_eigenvalue(2.0),
]
gradient = parameter_shift_gradient(expectation, [0.2, -0.4], rules=rules)
~~~

The module also exposes parameter_shift_jacobian for vector/tensor observables,
parameter_shift_vjp for reverse-mode products, trainable parameter selection,
and evaluate_shift_batch for one-call remote batch execution.

For the supported two-eigenvalue generator rule, this uses the exact analytic
parameter-shift identity rather than finite differences.
