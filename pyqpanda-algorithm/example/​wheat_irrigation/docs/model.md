# 模型、输入与结果介绍

## 从田块水分到 QUBO

每个开放的地块–日期对应一个二进制决策 `x[z,d]`：1 表示施用一次固定净灌水深 `a`，0 表示不灌溉。窗口外的决策直接固定为 0。JSON 的日期从 1 开始，内部数组从 0 开始。

根区植物可利用水量以 mm 表示，0 对应永久萎蔫点，`TAW` 对应田间持水量下的可利用储水量。程序的逐日动态为：

```text
ETc[z,d] = Kc[z,d] × ET0[z,d]
Peff[z,d] = effective_rain_fraction[z] × rainfall[z,d]
M[z,d] = M[z,d-1] + a×x[z,d] + Peff[z,d] + G[z,d] - ETc[z,d] + A[z,d]
```

未启用预测时，`ET0` 是用户提供的参考蒸散量，`A=forecast_adjustment_mm` 默认为 0。启用预测时，程序从历史气象计算 FAO56 标签，训练模型并将未来天气预报转换为 ET₀ 预测；土壤水分张力预测经标定后生成无新增灌溉水量基线，再用有符号的 `A` 接入上述动态。完整流程见 [forecasting.md](forecasting.md)。

这里使用潜在作物蒸散需求，没有用胁迫系数 `Ks` 调节实际蒸散，水量平衡不截断。

假设根区深度固定，FAO56 概念中的 `TAW = 1000(θFC - θWP)Zr`，允许耗水量 `RAW = p×TAW`。程序直接接受 `taw_mm`，不从土壤质地推断土壤参数。`allowable_depletion_fraction=p` 对应的根区水分阈值为 `(1-p)×TAW`。阶段标签本身不自动选择 Kc、p、目标或权重；这些量由输入提供。概念来源见 [SOURCES.md](SOURCES.md)。

农业加权目标为：

```text
H_obj = water_cost × a × Σx
      + Σ[z,d] stress_weights[z,d] × (M[z,d] - target[z,d])²
      + spatial_weight × 相邻地块同日灌溉对数
      + timing_weight × 同地块相邻两日灌溉对数
```

平方目标同时惩罚偏干与偏湿，其权重不是实测产量损失系数。相邻及连续灌溉项是软成本。贪心对照另有每天最多灌一个地块的规则，因此它的可选策略范围与 QUBO 存在差异。

令 `δ[z,d]=M[z,0]+Σ[t≤d](Peff+G-ETc+A)-target[z,d]`，以及 `S[z,t]=Σ[d≥t]w[z,d]`、`V[z,t]=Σ[d≥t]w[z,d]δ[z,d]`。预算惩罚前的线性项为：

```text
ℓ[z,t] = water_cost×a + a²×S[z,t] + 2a×V[z,t]
```

同地块两天 `t<u` 的水分记忆耦合为 `2a²×S[z,u]`，再叠加适用的空间/时间项；常数为 `Σwδ²`。保留常数使展开能量与直接水分目标可核对。

## 预测如何进入水量平衡

预测器输出日末土壤水分张力 `ψ̂[z,d]`，单位 kPa；用户提供的土壤水分特征曲线将其换算为根区可利用水量 `B[z,d]`，单位 mm。张力越大表示越干，不能直接把 kPa 当作水深。`B` 是规划期不新增灌溉时的固定基线；开始前的 `B[z,0]` 来自最后一次历史张力观测，经同一曲线换算并用于更新初始水量。

定义每日调整项：

```text
A[z,d] = B[z,d] - B[z,d-1] - (Peff[z,d] + G[z,d] - Kc[z,d]×ET0_hat[z,d])
M[z,d] = B[z,d] + a×Σ[t≤d]x[z,t]
```

两式与前面的逐日动态等价。`A` 可以为正或负，表示学习基线相对原水量平衡的差值，不是额外降水、取水或灌溉。预测中已经反映的降雨与蒸散不会被重复计入。

重新生成预测时，单独改变未来 Kc、毛管上升或有效降雨比例会被重新计算的 `A` 抵消，不独立改变学习基线。ET₀ 和雨量通过张力预测特征影响 `B`；ETc 在这一模式中是参考需求，不能同时解释为决定基线的独立水量平衡项。直接输入模式下 `A=0` 时，原有物理通量作用保持不变。

对每次优化，`B` 和 `A` 都是固定数据，与二进制决策无关，因此储水对灌溉决策仍然是仿射关系，平方水分目标仍可精确展开为 QUBO。精确的是这一固定基线模型内的代数关系；真实土壤在灌水后的张力、下渗和蒸散反馈仍可能非线性。该近似不在每个候选日程下重新递归预测，不保证累加灌水后水量不超过 TAW。实际滚动运行时，需要下一日的新观测、更新后的天气预报与灌水记录重新生成输入并求解。

## 毛取水预算和松弛编码

```text
event_net_m3 = dose_mm × zone_area_ha × 10
q = event_gross_m3 = event_net_m3 / irrigation_efficiency
Kvolume = min(开放决策总数, floor(water_budget_m3 / q))
```

未提供 `budget_events` 时，`K=Kvolume`；两者同时提供时取较小者。仅提供事件数时，毛取水预算按 `budget_events×q` 生成。浮点计算只在几个机器精度单位的边界内修正舍入误差，不允许实质超预算。

各地块必须共用面积、固定净剂量与效率，才能把体积约束转成 `Σx≤K`。`water_budget_m3` 是整个规划期的毛取水总量，不是每日渠首容量。固定剂量无法使用的剩余水量会保留。

```text
H(x,y) = H_obj(x) + λB × (Σx + Σj slack_weight[j]×y[j] - K)²
```

有界松弛位覆盖整数 `0..K`，如 K=2 时权重 `[1,1]`，K=4 时 `[1,2,1]`；K=0 不用松弛位。某些数值有多个编码，它们对应不同完整比特串。

所有非预算二次耦合都非负时，取 `λB > max(0,-min ℓ)` 足以保证全局最优解满足预算。实现使用 `1.1×max(1,-min ℓ)`，禁止负水分权重或负空间/时间权重。

## Ising 与 QAOA

导出的 QUBO 二次项仅保存一次，即 `i<j`：

```text
H(v) = c + Σ ℓi vi + Σ(i<j) qij vi vj
vi = (1-Zi)/2
Jij = qij/4
hi = -ℓi/2 - Σ(j≠i) qij/4
E0 = c + Σℓi/2 + Σ(i<j)qij/4
```

若改用对称矩阵 `v.T @ Q @ v`，需要把每个非对角系数均分到上下三角。

QAOA 从均匀叠加态开始，在每层先施加 `exp(-iγH)`，再施加 `exp(-iβΣX)`。最大非恒等 Ising 系数的绝对值作为归一化尺度。默认 `pyqpanda_alg` 后端将归一化 Ising 系数封装成 `PauliOperator`，调用算法库的 `QAOA` 电路实现；显式选择的 `numpy` 后端直接演化态矢量。能量常数只产生全局相位，但在期望值报告中保留。

适配层将 `QAOA.problem_dimension` 设置为完整变量数，包含零系数变量与预算松弛位，避免末尾变量在算符简化后丢失。每次优化评估调用 `run_qaoa_circuit(gammas, -betas, shots=-1)` 得到完整概率分布；算法库的 RX 角约定与本项目相反，因此传入负的混合角。`pyqpanda` 是 `pyqpanda_alg` 的兼容名称，不再使用应用内直接构造的门电路。

COBYLA 将上述概率分布与本模型的完整能量表相乘，优化精确期望，然后用给定种子的 NumPy 多项分布抽取有限 shots；两个 QAOA 后端遵循相同的抽样方式。优化达到评估上限时保留已评估的最佳参数，并记录停止状态，不把达到预算等同于收敛。

态矢量索引为 `Σv[i]×2**i`。输出的 `*_x0_first` 字符串从左向右是 x0、x1……，与常见 `|q[n-1]…q[0]>` 字符串方向相反。

## 输入字段

所有数值必须有限，不能含 NaN/Infinity。下表“逐日”表示可提供标量或长度为 `days` 的数组。

| 顶层字段                                        | 单位 / 校验                                            |
| ----------------------------------------------- | ------------------------------------------------------ |
| `name`, `source_note`                           | 字符串；来源应区分合成、实测或预测                     |
| `region`, `crop`                                | 非空字符串；默认 generic、winter_wheat                 |
| `start_date`                                    | 可省略或 null；否则为 YYYY-MM-DD，整个规划期必须可表示 |
| `days`                                          | 正整数                                                 |
| `water_budget_m3`                               | 非负毛取水总量 m³；与 budget_events 至少提供一个       |
| `budget_events`                                 | 可选非负整数，不超过开放地块–日期总数                  |
| `dose_mm`, `zone_area_ha`                       | 正数，净灌水深 mm / 每地块统一面积 ha                  |
| `irrigation_efficiency`                         | (0,1]，默认 1，表示根区净水/渠首取水                   |
| `water_cost`, `spatial_weight`, `timing_weight` | 非负目标权重，必填；不表示货币                         |
| `zones`                                         | 非空地块数组；名称唯一                                 |
| `adjacency`                                     | 可省略；地块名称对，无自环、重复或未知地块             |

| 地块字段                                     | 单位 / 校验                                                            |
| -------------------------------------------- | ---------------------------------------------------------------------- |
| `name`                                       | 非空名称                                                               |
| `taw_mm`                                     | 正数，根区总可利用水量 mm                                              |
| `initial_moisture_mm`                        | [0,TAW]，规划开始前根区水量 mm                                         |
| `window_days`                                | 不重复的 1..days 整数列表，单地块可为空；全场景至少一个开放窗口        |
| `target_mm`                                  | 逐日，[0,TAW]                                                          |
| `stress_weights`                             | 逐日，非负                                                             |
| `crop_coefficient`                           | 逐日 Kc，非负                                                          |
| `et0_mm`, `rainfall_mm`, `capillary_rise_mm` | 逐日 mm/天，非负                                                       |
| `forecast_adjustment_mm`                     | 可省略，默认 0；逐日 mm/天，允许正负，须为有限值；预测基线的代数调整量 |
| `effective_rain_fraction`                    | [0,1] 标量                                                             |
| `growth_stage`                               | 非空字符串或逐日字符串数组；默认 unspecified                           |
| `allowable_depletion_fraction`               | 逐日 p，[0,1]；省略时用 0.55，仅为程序默认值                           |

建议从 `--export-input` 生成的完整 JSON 开始修改。输入未包含生育期参数时，默认值只是兼容行为，不意味着适用于当地小麦品种、土壤或天气。

## 结果中的可行性

`budget_feasible` 检查灌溉事件数是否 ≤K。`zero_slack_residual_probability` 还检查实际抽到的松弛位是否令等式成立。候选按去掉松弛惩罚后的农业目标排序，但报告保留原始完整能量与残差；不会修复或用精确解替换失败的量子样本。

`below_threshold_zone_days` 是水分低于 `(1-p)TAW` 的地块–天数；`zone_diagnostics` 进一步按地块与生育期汇总。`moisture_excursions` 记录低于 0 或高于 TAW 的时间。

毛取水减净水报告为 `conveyance_loss_m3`，是统一效率假设下的总差额，并未细分渠道渗漏、蒸发和田间损失。这里没有泵站能耗、地下水位、非线性下渗、产量或全生育期作物模型。
