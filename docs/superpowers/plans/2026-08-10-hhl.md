# Stable HHL Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a stable small-scale HHL solver with validated Hermitian inputs, circuit/resource construction, local quantum-state results, runtime sampling/observable execution, and explicit tomography reconstruction.

**Architecture:** Input normalization and matrix padding are independent of circuit synthesis. HHL builds a measurement-free core circuit, then LocalBackend or runtime-specific measurement plans obtain the requested result. Complete classical-vector reconstruction is opt-in and represented as additional tomography tasks.

**Tech Stack:** NumPy, SciPy linear algebra, pyqpanda3 circuits/Oracle, pyqpanda_alg.execution, pytest.

## Global Constraints

- Inputs are finite Hermitian square matrices and matching finite vectors.
- Non-power-of-two systems use a documented reversible padding rule.
- Singular and over-threshold ill-conditioned systems fail before task submission.
- Runtime defaults to success probability and requested observables, not full-vector reconstruction.
- `reconstruct=True` reports tomography circuit and shot cost before submission.
- Existing notebook function names remain available as compatibility wrappers.

def normalized(vector):
    return vector / np.linalg.norm(vector)


def test_hhl_local_matches_diagonal_solution_direction():
    matrix = np.diag([1.0, 2.0])
    vector = np.array([1.0, 1.0])
    result = HHL(matrix, vector, precision=1e-3).run(reconstruct=True)
    expected = normalized(np.linalg.solve(matrix, vector))
    assert abs(np.vdot(expected, normalized(result.classical_vector))) > 0.99
    assert result.residual < 0.05
