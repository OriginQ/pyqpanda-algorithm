# Stable VQE Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a stable Hamiltonian-level VQE with built-in hardware-efficient Ansatz, local and qpanda3-runtime execution, custom optimizer support, and resumable results.

**Architecture:** VQE owns Hamiltonian validation, Ansatz construction, and a classical optimization state machine. Energy evaluation is delegated to ExecutionBackend estimation or a VariationalSession; result and optimizer state are independent of transport details.

**Tech Stack:** pyqpanda3 Hamiltonian/VQCircuit, NumPy, SciPy optimize, pyqpanda_alg.execution, pytest.

## Global Constraints

- Input is a pyqpanda3 `Hamiltonian`; chemistry preprocessing is out of scope.
- Default CPU calls require no runtime installation.
- Runtime prefers VQSession and uses estimate batches when VQSession is unavailable.
- Runtime failure never falls back to CPU.
- Built-in optimizer state is checkpointable; custom optimizer recovery is explicitly reported.
