# Stable Shor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add stable small-scale Shor factorization with classical preprocessing, generic modular exponentiation, quantum order finding, bounded retry/recovery, resource estimation, and runtime execution provenance.

**Architecture:** Classical preprocessing and order recovery are pure deterministic modules. Circuit arithmetic builds order-finding programs from only the public modulus and selected base. A resumable algorithm state machine coordinates base attempts and sampling tasks, and every result states whether a quantum task was actually used.

**Tech Stack:** Python integer arithmetic, NumPy, SymPy primality helpers, pyqpanda3 circuits, pyqpanda_alg.execution, pytest.

## Global Constraints

- The public API accepts general positive integers but only promises quantum execution when resources fit the backend.
- Circuit construction cannot use known factors or known order.
- Even numbers and perfect powers may return through explicit classical preprocessing.
- Prime input returns `is_prime=True` with no quantum task.
- Only results that executed quantum order finding count toward QPU qualification.
- Retry count is finite and checkpointed.
